# Lung patient-derived cells (GSE165611) next to TCGA-LUAD tumours

102 PDC RNA-seq profiles (RSEM FPKM from GEO, log2(FPKM+1)) and TCGA-LUAD primary tumours, on 18622 shared genes. a: raw; b: each gene z-scored within its own dataset (the paper's batch correction). Colours: PDC histology from GEO. The drug-response values for these PDCs are not public, so they cannot be used to train the model; the lung analysis uses GDSC/CTRP lung adenocarcinoma cell lines instead.
