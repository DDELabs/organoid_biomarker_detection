# All sets and drugs in one plot

Each row is one lab-model set and one drug. The paper's procedure picked one pathway from the lab models; TCGA patients were split at the median of that pathway. Red circles: patients given the drug; blue squares: patients with no drug record. HR > 1 means predicted non-responders died sooner (the expected direction). Rows: 34; log-rank p < 0.05 in treated patients: 5 (of which 3 in the expected direction); permutation empirical p < 0.05: 2. Numbers in `SUMMARY/tables/cross_set_summary.tsv`.
