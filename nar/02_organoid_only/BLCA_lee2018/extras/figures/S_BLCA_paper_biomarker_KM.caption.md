# The pathway the paper reported for bladder cisplatin

The paper reports 'amino acid synthesis and interconversion (transamination)' as the bladder cisplatin biomarker.
In the paper's own coefficient plot (Fig. 2f) this pathway is rank 2, not rank 1, although the paper's code tests rank 1.
Here the same pathway is used directly, with the sign of our organoid Ridge coefficient. Rows: paper source-data NES (top), current GDC data (bottom).

- paper, treated: our Ridge rank 6; n = 79, deaths = 20, log-rank p = 0.0311, HR = 2.66 (1.06-6.69); 5-year survival 0.70 (pred. responders) vs 0.49.
- paper, untreated: our Ridge rank 6; n = 288, deaths = 79, log-rank p = 0.0871, HR = 0.67 (0.42-1.06); 5-year survival 0.41 (pred. responders) vs 0.59.
- current, treated: our Ridge rank 30; n = 79, deaths = 28, log-rank p = 0.0634, HR = 2.03 (0.95-4.34); 5-year survival 0.66 (pred. responders) vs 0.50.
- current, untreated: our Ridge rank 30; n = 283, deaths = 131, log-rank p = 0.0212, HR = 0.66 (0.47-0.94); 5-year survival 0.31 (pred. responders) vs 0.42.

Paper: treated n = 77, p = 0.01; untreated n = 294, p = 0.066.
