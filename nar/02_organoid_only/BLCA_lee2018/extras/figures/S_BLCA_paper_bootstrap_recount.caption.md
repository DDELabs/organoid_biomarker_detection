# Paper's bootstrap (Fig. 4f) recounted from its source data

The paper ran 10000 random pathway sets. A set 'wins' if a pathway at a given coefficient rank predicts survival (p<0.05) and differs between resistant and sensitive isogenic cells (p<0.05). The paper's biomarker reached rank 2. Random sets reaching rank 1: 66; rank 2: 74. Empirical p (rank <= 2) = 0.0140 (paper: 0.014). No pathway met both criteria in 6366 sets.
