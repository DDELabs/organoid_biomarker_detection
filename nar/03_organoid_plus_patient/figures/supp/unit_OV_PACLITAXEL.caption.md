**Supplementary figure for OV_PACLITAXEL (ovarian, paclitaxel (with platinum)).**
Lab models: ovarian_vias2023:PACLITAXEL n=14 dropped_axes=9. Design: leave-one-cohort-out.
(a) Held-out concordance per cohort using the 86 network-proximal pathways (C-index for survival, AUROC for response; 0.5 = chance) for organoid-only (orange), patient-only (light blue) and joint (green) models. (b) The same using all 673 pathways. (c) Treatment x score interaction (ratio < 1: the score matters more in drug-treated patients than in the comparison group), network shortlist.
(d, e) Hazard ratio per SD of the score in held-out treated patients with 95% CI, shortlist and all pathways. (f) Interaction, all pathways.
Remaining rows: Kaplan-Meier curves in each held-out survival cohort, treated patients split at the cohort median score, one column per model (shortlist features). Log-rank p in each title.
