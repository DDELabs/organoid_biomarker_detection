# GSE109211 — STORM adjuvant sorafenib trial (sorafenib arm ONLY)

Pinyol R, et al. Molecular predictors of prevention of recurrence in HCC with sorafenib as
adjuvant treatment and prognostic factors in the phase 3 STORM trial. Gut 2019;68:1065-1075.
doi:10.1136/gutjnl-2018-316408. Platform GPL13938 (Illumina HumanHT-12 WG-DASL v4, FFPE).
GEO series: 140 patients (67 sorafenib, 73 placebo). Only the 67 sorafenib samples are here.

## Provenance
NCBI GEO / EBI are blocked from this environment. Files were taken from the ENLIGHT data
release (Dinstag et al., Med 2023; bioRxiv 10.1101/2022.02.27.481627), which mirrors the
GEO-processed GSE109211 sorafenib arm with HUGO symbols:
- https://raw.githubusercontent.com/PangeaResearch/enlight-data/main/Data/Sorafenib.csv
  sha256 7da47f11bcdff7fb497cb26c7322ee1581d7eb4b0c7ea29f60f8a4d29e346b3d
- https://raw.githubusercontent.com/PangeaResearch/enlight-data/main/Data/drug_response_classifications.csv
  sha256 fc6148f25f38a12467f4c5e834bc1dda0ac1cabe8f0ae1e31841fb154e09eed5 (rows with Dataset == "Sorafenib")
Identical copies exist in bhklab/synthLethal and gilbenc/2024_STAMP_Explainatory_Translational_Sorafenib.

## Files
- expression.tsv.gz: 20,727 genes x 67 samples (GSM IDs); column `gene` = HUGO symbol.
  Values are on the LINEAR scale as distributed by ENLIGHT (range ~73 to 15,000; median ~120).
  Probes are already collapsed to genes. Apply log2 before use. Values are unchanged apart from
  rounding to 5 significant digits.
- clinical.tsv: sample, arm (all "sorafenib"), response ("responder" n=21 / "non-responder" n=46,
  matching the 21/46 counts in the paper and the GEO `outcome` field), response_binary,
  rfs_months / rfs_event (EMPTY: per-patient RFS times are NOT in GEO), enlight_response,
  geo_title_id (BSxxx FFPE ID, available for 60/67 samples from the AITL GEO_annotations.ipynb
  printout, hosseinshn/AITL), aitl_label_RS (AITL R = non-responder, S = responder; 60/60 agree
  with ENLIGHT).

## Limitations
- No placebo arm here, so a treatment-by-biomarker interaction test is not possible with these
  files. The placebo samples (73) need GEO GSE109211_series_matrix.txt.gz (characteristics:
  treatment, outcome) from an unblocked host.
- The response label is binary. It is derived from RFS in the trial (Pinyol 2019); it is not
  a time-to-event outcome.
